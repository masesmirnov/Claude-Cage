# Cage v0.1.5-alpha.2

Proxy settings can now combine relays and the final exit directly, without editing YAML. When you choose chained proxy, nodes are listed in the actual connection order, and the final exit seen by the target site is shown. Combinations across subscriptions are supported. Configuration is applied together. Subscription updates keep the combination, and a failed attempt keeps a draft you can retry.

This version also includes these improvements:

- Moved IP change rules into the network and proxy page. The exit rule entry in network checks also points to the same place. Improved help, inline selection, and leave warnings for unapplied changes.
- The proxy and status bar now use the same HTTP round-trip latency definition. The note explains that it usually doesn't include connection setup overhead, so it is distinct from the first-page-open time.
- Adjusted timeout handling for proxy connections and encrypted DNS. Retries happen inside the current proxy and do not fall back to a direct host connection.
- After environment setup fails, you can retry using existing files. Image and tool downloads support digest-verified caches and resume. Tool installs avoid duplicate downloads.
- Updated the promo video source, horizontal and vertical interface assets and social media images.

## Installation and updates

macOS provides a Developer ID-signed, notarized DMG for Apple Silicon and macOS 14 or later. Windows keeps the x64 unsigned preview installer, which must be installed and updated manually and is not in the signed automatic update channel. Linux provides a DEB for Debian 12 / Ubuntu 24.04 x86_64, installed and updated with the system package manager.

Save your files, stop the environment and quit Cage before upgrading. Accounts, subscriptions, bookmarks, projects and persistent VM data are kept. The attachments for all three platforms share SHA256SUMS, and source code for Mihomo and the QEMU main program is provided.

## Verification scope

Locally, the full Go test suite, related race checks, frontend lint / 50 tests / build, and 48 release-process tests all passed. The real control service and bundled Mihomo verified local two-hop chaining, single-node switching, and no direct fallback when the exit fails. Interface testing covered cross-source selection, keyboard operation, draft retention, failed retries, leave confirmation and narrow screens. The macOS updater verified signatures, failure rollback and data retention, and after a local install, the original account and key data were kept.

Before public release, the matching commit must still pass CI on all three platforms, the final macOS DMG must be signed and notarized, anonymous download must be verified, and the website must be checked. The actual status and source commits are recorded in this GitHub Release. Unfinished items should not be treated as passed based on this note. Real residential nodes, public Claude requests, a fresh Mac first start, Windows 10/11 and Linux/KVM desktops still need hands-on testing.
