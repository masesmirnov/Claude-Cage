# Cage v0.1.6-alpha-preview

From "SSH host" in the workbench sidebar, you can connect to a cloud Cage. Files, projects and the network all run on the selected server. On first deployment, verify the host fingerprint. After you click "Deploy and connect", the server installs the environment from the Debian base image. If the service has stopped, reconnecting starts it. Supports Linux x86_64 VPS with a configured systemd user service, cgroup v2 and the permissions required for rootless containers. KVM is not needed.

Opening Cage still goes to the local workbench by default. Connecting to a server doesn't require starting the local VM first. If local tasks are running, you can keep them running, or stop them before switching to free up memory.

- Supports choosing the environment storage location, and improves persistent disk paths, free-space checks and migration. The first install shows download and preparation progress, and fixes component fetching and retries on weak networks.
- Fixed Windows VM firmware lookup and WHPX CPU configuration. Improved Linux install dependency detection.
- Improved browser developer tools, download handling and network recovery. Monitoring errors that have been resolved are cleared once the new network authorization takes effect.

The macOS installer is for Apple Silicon. Windows x64 provides an unsigned preview installer that must be installed manually. Linux x86_64 installs or updates with the DEB. Save your work and quit Cage before upgrading.
