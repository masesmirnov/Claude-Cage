# Cage v0.1.7

This is the first official release of Cage. macOS, Windows and Linux users can choose an installer on the [website](https://lee-xeo.github.io/Claude-Cage/#download). Android has an arm64 APK, and iPhone users can sign and install from Xcode by following the [phone connection guide](https://lee-xeo.github.io/Claude-Cage/docs/mobile/).

## Upgrading from the release candidate

Save your work and quit Cage first, then install the official release for your system. Your existing configuration, accounts and guest disk keep being used. After opening the workbench, if you are prompted to update the environment tools, you can finish the update under "Settings → Environment and recovery → Versions and components".

- **Reopening an existing environment.** When the base template is missing or the installation is unfinished, an existing virtual machine can still start from its own disk. Creating or resetting an environment needs a usable template, and a reset completes this check before the original environment is stopped or deleted.
- **Downloading large toolkits.** Servers that support ranges can be downloaded from with up to 4 parallel connections. After an interruption, saved progress can be reused. When the server does not support ranges, the download falls back to a single connection automatically. The whole file is still verified after the download. The actual speed-up depends on the route and the server's rate limits.
- **Using GitHub in the terminal.** New environments install GitHub CLI by default, and existing environments can use it after updating the tools. Run `gh auth login` in a Cage terminal and authorize with your own GitHub account to work with commits, PRs and issues according to your repository permissions. [Terminal guide](https://lee-xeo.github.io/Claude-Cage/docs/workbench/)
- **Installing the official latest Claude.** Claude Code and Claude Desktop resolve the official latest version when they are actually downloaded and installed, and a newer installed version is kept. When a download or verification fails, you can fix the network and retry without rebuilding the account or environment.
- **Switching proxy nodes.** Fixed exit rules are saved with the selected node. After switching nodes, Cage checks that node's exit before restoring internet access, so the address bound to the previous node is not used for the new one.
- **First setup and recovery.** macOS improves the project folder authorization window and the fixed exit confirmation flow. Windows fixes the registration helper timing out when an installation is resumed, and Windows PowerShell 5.1 failing to read the component manifest script.
- **Terminal and guest screen.** Improves copying a terminal selection, the clipboard between a Windows host and a Linux guest, cursor display and wheel response in native guests, and reduces reconnections caused by brief pauses of the screen.
- **Windows screen and Chinese input.** Improves how Desktop displays at different scale factors, the toolbar and Chinese input. Browser scrolling reuses continuous frames and takes fewer repeated screenshots. Manual acceptance of native menus under different Windows display scaling configurations is still pending.

The release attachments include the desktop installers, the Android APK, the matching source archive and `SHA256SUMS`. If an existing installation runs into problems, keep the configuration and guest disk, and record the first error in the operation details.
