# Cage documentation

If you are new to Cage, start with installation and proxy setup; if an existing environment has problems, go straight to troubleshooting and recovery. Public installers and the acceptance scope of each version are on [GitHub Releases](https://github.com/Lee-xeo/Claude-Cage/releases); the product introduction is on the [project homepage](https://claude-cage.com/).

## Usage and feedback

The [online documentation](https://claude-cage.com/docs/) for everyday use offers categories, full-text search and section links. Its source is in [guide/](guide/index.md), covering multiple accounts, the browser, phones, the cloud, settings and troubleshooting; the table below keeps direct links to installation, platform notes and maintenance material.
